<h2>Funcionalidade</h2>
<p>Um projeto com o objetivo de simular um painel rodoviário com HTML, CSS e JS</p>
<p>mostrando a temperatura atual e condição do clima através de ícones. </p>
<p>Exibe hora, data e dia da semana em tempo real</p>
<p> obs: a localização escolhida para demonstração foi a cidade de Carapicuíba </p>

<h2>Clima e Temperatura</h2>
<p> A API utilizada  foi a Open-Meteo</p>

<h2>Sobre o Painel</h2>
<p> Os dados exibidos no painel sobre horário, destino, viação, portão e status</p>
<p>são estáticos e meramente ilustartivos</p>
